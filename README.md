# Telegram MCP

Локальный MCP-сервер для чтения и отправки сообщений Telegram через пользовательскую сессию TDLib. В конфигурации указываются аккаунты, разрешённые чаты и операции для каждого чата.

## Требования

Инструкция ниже предназначена для macOS. Нужны Python 3.11+, TDLib и `qrencode` для входа по QR. Для подключения понадобится MCP-клиент с поддержкой stdio.

## Установка

```bash
brew install tdlib qrencode
git clone https://github.com/shamanomania/telegram-mcp.git
cd telegram-mcp
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp -i telegram-profiles.example.json telegram-profiles.json
```

Откройте `telegram-profiles.json` и замените пример на свои настройки. Укажите для каждого чата `chat_id`, название и один из уровней доступа: `read`, `send` или `read_write`. Для ссылки вида `https://t.me/c/1234567890/42` значение `chat_id` равно `-1001234567890`. Для чтения публичных ссылок добавьте `username` чата без `@`. Поле `user_id` закрепляет профиль за конкретным аккаунтом, если его ID известен.

## Вход в Telegram

```bash
.venv/bin/python -B server.py login --account primary
```

При первом входе понадобятся `api_id` и `api_hash` приложения из [Telegram API development tools](https://my.telegram.org/apps). В приложении Telegram откройте **Настройки → Устройства → Подключить устройство** и отсканируйте QR из Терминала. При запросе введите пароль двухэтапной аутентификации в том же окне. Ввод скрыт. Для входа по номеру телефона добавьте `--phone`.

Перед сообщением об успехе команда проверяет текущую сессию на сервере Telegram. Если Telegram отозвал её, команда начинает новый вход. Реквизиты приложения и ключ шифрования хранятся в системном хранилище ключей. База TDLib, профиль чатов и журнал отправок хранятся локально и исключены из Git.

## Подключение MCP-клиента

Для Codex выполните команду из каталога репозитория:

```bash
codex mcp add telegram-mcp -- "$PWD/.venv/bin/python" -B "$PWD/server.py"
```

Для другого stdio-клиента укажите абсолютный путь к `.venv/bin/python` в качестве команды и передайте аргументы `-B` и абсолютный путь к `server.py`. Если TDLib установлена вручную, задайте `TDLIB_LIBRARY` с путём к библиотеке.

## Инструменты

| Инструмент | Что делает |
| --- | --- |
| `list_telegram_chats` | Показывает локально настроенные аккаунты, чаты и права. |
| `read_telegram_message` | Читает сообщение по ссылке `t.me` или по числовому `message_id` из MCP. |
| `read_telegram_history` | Возвращает историю чата от новых сообщений к старым. Для следующей страницы передайте `next_before_message_id` как `before_message_id`. |
| `send_telegram_message` | Отправляет текст. Укажите `parse_mode: "html"` для Telegram HTML. |

После настройки можно попросить клиента: «Покажи последние пять сообщений из чата `example-group` аккаунта `primary`».

Для отправки задавайте отдельный `request_id` каждой операции. При повторе передавайте прежний ключ и тот же текст. Подтверждённая операция возвращает сохранённый ID сообщения. При неопределённом исходе проверьте чат. Повтор с тем же ключом будет заблокирован.
